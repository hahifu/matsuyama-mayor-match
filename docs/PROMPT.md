# 再現プロンプト

以下のプロンプトで、同じ方針のページをMuseに作らせることができます。

---

松山市長選挙（投票日2026年11月15日、立候補予定者は木下豪・田中エリナ・中野泰誠の3人、いずれも無所属・新人）の投票先選びを助けるwebページを作ってください。

目的と原則:
- 大事なのは本人が投票に行くことです。正解の名前を当てるページにはしないでください。
- 政治に興味のない人が、見て、触って、投票に行くところまでが目標です。新聞社のボートマッチのような、説明文を読ませる形式にはしないでください。
- 候補の公約は、公式発表を整理した公開情報（自治スコープ等）から実在のものだけを使ってください。創作は禁止です。

仕掛け:
- アキネイターや方言チャートのように、日常の暮らしについての質問（買い物の値上がり、子どもの預け先、病院、駅前など政策用語のないもの）を7問、大きなボタンで1問ずつタップして進める形にしてください。
- 途中には絞り込まれていく感覚、結果の直前には短い「集計中」の間を入れてください。
- 結果は、嗜好に最も近い候補の1位と2位を同格に並べてください。それぞれに、本人の回答と結びついた理由（実在の公約）、2人の強みの違い、迷うときに考える問いを付けてください。最終判断は本人に残してください。
- 結果の直下に、期日前投票など実際に投票するための情報を置いてください。

デザイン（フラット・ゲーム）:
- 紺色の単色背景、完全フラット。グラデーション、キラキラ、ツヤのある装飾は使わないでください。ゲーム感は装飾ではなくレイアウトとコピーで作ってください。
- 生成AIのイラスト（平均的な顔やタッチのキャラクター）は使わないでください。候補者はフラットな色タイルや実在の写真で表してください。画像の中に文字を描かず、文字はすべてHTMLテキストで組んでください。
- ファーストビューは、質問形の大きな見出し、候補のタイル、単一の大きなスタートボタンだけにしてください。説明文は置かないでください。スタートボタンはページに1つだけです。
- 最も見せたい要素は1点に絞り、他は意図的に弱くして、余白で視線の順番を作ってください（どこも同じ細かさ・同じ強さにしない）。
- スマホ前提です。主要ボタンは画面下半分（親指の範囲）に、タップ領域は44px以上、見出しは36px級、本文は16px以上。比較表や出典などの詳細は折りたたみに回してください。
- デザインの意図や制作側の話は、ページの中に書かないでください。

検証:
- 異なる回答パターンで最後まで操作し、結果が実際に変わることを確認してください。
- 出来上がったら、要求の一覧と1つずつ照合した結果を報告してください。
