# テスト記録

## 要求（利用者の要求のみ）

1. 松山市長選挙（市長選のみ）を対象とし、最もリターンの高い候補を選ぶ助けになること
2. 重視度マッチ型であること
3. 政治に興味のない人が見て・触って、投票行動に移ることを目標とすること（新聞社のボートマッチの形式を踏襲しない）
4. アキネイター／方言チャート型の仕掛け（日常の質問に答えると結果が明かされる楽しさ）を取り入れること
5. 大事なのは本人が投票をすることであり、結果は嗜好に最も近い1位・2位を提示して本人が考える機会を提供すること
6. トップの文章は読まれない前提で、面白そうだからボタンを押す初動の作りにすること
7. スマホ向けwebサービスのベストプラクティスに倣うこと
8. 「AIイラスト臭」のアンチパターンを避けること
9. デザインの話（作り手側の都合）を利用者に見せないこと／開始ボタンは1箇所だけにすること
10. リファインされたデザイン案3案から利用者が選んだ「R2 フラット・ゲーム」で作ること
