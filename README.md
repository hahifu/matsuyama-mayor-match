# 松山市長選 候補マッチ

2026年11月15日投票の松山市長選挙で、投票先を考えるためのページです。

日々の暮らしについての質問7つにタップで答えると、嗜好に最も近い候補と次に近い候補の2人を並べて表示します。それぞれに、自分の回答と結びついた理由（候補者が実際に公表している公約）と、2人の強みの違い、迷うときの問いが付きます。最後に決めるのは本人です。このページの目的は、正解の名前を当てることではなく、投票に行くことです。
